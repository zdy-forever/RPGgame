# Asset Attribution

## Visual Assets

The imported raster artwork used in this project was generated using OpenAI image generation.
Some UI, including the Hub background, debug geometry and the potion bottle/count, is drawn by code
and is not an imported image asset.

These visual assets are not covered by the proprietary license applied to the project's source code.

See `art/README.txt` for the asset pack description and `art/ASSET_MANIFEST.csv` for the per-file manifest.

Reviewed 2026-09-30: the manifest contains 232 PNG entries. The procedural potion icon adds no file
and changes no image provenance. Rendering and testing boundaries are documented in
`Activity_2/docs/ART_INTEGRATION.md` and `Activity_2/docs/TEST_COVERAGE_REVIEW.md`
(paths relative to the repository root, outside the assets resource root).

## Music

All music used in this project was generated using Suno during an active paid subscription.

The audio assets are used under the rights associated with the applicable Suno subscription and are not covered by the proprietary license applied to the project's source code.

See `audio/README.md` for track filenames and playback details.
